# Первый запуск GooseCraft 0.6.1 на Windows 10 x64

[Скачать Windows x64 ZIP 0.6.1](https://github.com/kokasikhorik-bot/GooseCraft/actions/runs/41053468183/artifacts/12976740022),
успешный CI #41053468183, source `9188988`.
[Актуальный отчёт](https://github.com/kokasikhorik-bot/GooseCraft/blob/main/docs/github-ci.md). В 0.5 мир расширен до девяти чанков и появился файл
сохранения. В 0.6 новые миры получают рельеф по seed; старые сохранения
сохраняют свои блоки. Старые 0.3/0.4 имели только временный одночанковый мир.
Для скачивания Actions artifact может потребоваться вход в GitHub.
Для UTF-8 аргументов путей используется app manifest Windows 10 1903+.
Проверенный builder — Windows Server 2022; пользовательская Windows 10 GUI
проверяется отдельно. На более старых сборках Windows 10 Unicode argv не проверен.

1. Распакуйте весь ZIP в отдельную папку. Оставьте оба `.exe`, `goosecraft.cmd`
   и лицензионные уведомления рядом. Не запускайте клиент внутри ZIP.
2. Запустите `goosecraft.cmd`. Goose, Python, Java и инструменты разработки
   устанавливать не требуется.
3. Для нового мира должно открыться окно с зелёными холмами, янтарной толщей
   земли и прицелом. Существующее сохранение откроется с прежними блоками.

| Управление | Действие |
| --- | --- |
| W/A/S/D | Вперёд / влево / назад / вправо |
| Мышь | Повернуть взгляд; курсор захватывается окном |
| Стрелки | Альтернатива мыши для обзора |
| Space | Прыжок с опоры |
| Левая кнопка мыши | Удалить один выбранный блок за нажатие |
| Правая кнопка мыши | Поставить блок рядом с выбранной гранью |
| 1 / 2 | Зелёный / янтарный материал |
| Escape | Пауза и освобождение мыши |
| Enter или клик | Продолжить игру; клик продолжения не разрушает блок |
| R | Вернуться на старт и восстановить направление взгляда |
| F5 | Сохранить изменения блоков |
| F10 / закрыть окно | Сохранить изменения и выйти |

Потеря фокуса ставит игру на паузу; после возвращения нажмите Enter или кликните.
До блока можно дотянуться на шесть мировых единиц. Установка внутри игрока,
поверх занятой клетки и за пределами мира запрещена. Падение в отверстие
возвращает на старт. Горизонтальные края площадки ограничивают движение.

Мир — девять чанков, область X/Z от -16 до 32, высота 16 и два материала.
Можно ходить и редактировать через стыки без дополнительных действий.
Нет Minecraft-текстур, серверов,
инвентаря, крафта и загрузки существующих миров.

## Сохранение

Обычный запуск открывает `%LOCALAPPDATA%\GooseCraft\worlds\default-v1.gcw`.
Если файла нет, создаётся новый рельеф (seed 12345). F5 и штатный выход сохраняют
блоки; следующий запуск их восстанавливает. Положение игрока, выбранный
материал и счётчики не сохраняются. Надписи `UNSAVED`, `SAVED`, `SAVE ERROR`
показывают состояние. Принудительное завершение процесса может потерять
последние несохранённые изменения; пользуйтесь F5.

`goosecraft.cmd --no-save` запускает временный мир. `goosecraft.cmd --world "D:\Games\My World.gcw"`
задаёт отдельный путь. Относительный путь `--world` считается от рабочего
каталога, а путь по умолчанию от него не зависит. Диагностические replay,
preview и single-chunk режимы временные, пока явно не указан `--world`.
Своё сохранение лучше не помещать в папку исходников.

Чтобы посмотреть другой рельеф без записи: `goosecraft.cmd --no-save --seed 1`.
Чтобы создать отдельный мир: `goosecraft.cmd --world "D:\Games\Hills.gcw" --seed 12345`.
Путь должен быть новым; для повторного открытия уберите `--seed`. Seed —
0..4294967295. Указывать его для существующего файла нельзя (exit 2).
`--demo-world --no-save` открывает старую площадку со столбиками.

Повреждённый или неизвестный формат не перезаписывается: запуск завершится
с ошибкой 5. Ошибка сохранения при выходе даёт 6. Можно временно запустить
`--no-save`, а исходный файл оставить для диагностики. Формат `.gcw` собственный,
не совместим с Minecraft; [описание](world-format.md).

## Что проверить при первом запуске

Пройтись по холмам, прыгнуть на ступень, посмотреть вниз, удалить блок под
прицелом и поставить выбранный материал правой кнопкой. Затем проверить
Escape/Enter и переключение на другое окно. Дойти за старую границу площадки,
нажать F5, выйти и проверить изменения после повторного запуска.
Для обратной связи полезны версия
Windows, модель видеокарты, появился ли кадр и какое действие не сработало.

Если окно сразу закрывается, откройте обычную командную строку в папке сборки
и выполните `goosecraft.cmd > first-run.log 2>&1`. После завершения процесса
сообщения останутся в `first-run.log`. Команда
`goosecraft.cmd --screenshot first-frame.png` сохраняет последний кадр при выходе.
Консольная проверка без графики: `goosecraft.cmd --headless --ticks 20`.
Проверка сохранения без GUI:
`goosecraft.cmd --headless --inspect-world "%LOCALAPPDATA%\GooseCraft\worlds\default-v1.gcw"`.
`BUILD-INFO.json` рядом с программой содержит версию, исходный commit и run CI.

Облачные проверки пока подтверждают Windows-сборку/CLI и Linux-рендеринг.
Окно на пользовательской Windows 10 и её видеодрайвере должен подтвердить
реальный локальный запуск; успешный Linux-тест этого не доказывает.
В 0.6.1 исправлены два наблюдавшихся просвета greedy-меша, проверены другие
seed и ракурсы на Linux lavapipe. [Проверки и ограничения](stitch-results.md).
Это не заменяет проверку на Windows 10 и физическом GPU.
