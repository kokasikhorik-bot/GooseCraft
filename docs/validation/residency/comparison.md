# Ограниченная GPU-резидентность: локальный прогон

GooseCraft 0.9.0, 81 CPU-чанк, seed 12345, окно 640×480, одинаковые игрок/радиус рисования 2.
Baseline `--retain-meshes` хранит все меши, но применяет тот же draw window.
Один последовательный сеанс на конфигурацию: 180 кадров, 30 warmup, retained 150.
Linux, GCC 12.2, Mesa 22.3.6 lavapipe, Xvfb, network=none; screenshot/readback выключен.

Снижение запрошенной live mesh capacity: **70.92%**.
CPU-блоки не выгружались. Это не полная VRAM/RSS; SDL может отложить уничтожение буферов.
CPU wall включает ожидание предыдущих submit/present; не GPU timestamps/FPS. Один прогон
не устанавливает устойчивый коэффициент скорости. Оптимизация имеет цену повторного построения при возврате.
