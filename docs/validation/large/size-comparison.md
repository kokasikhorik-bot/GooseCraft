# Локальная стоимость 9 и 81 чанка

GooseCraft 0.8.0, seed 12345, одна и та же неподвижная камера, окно 640×480.
Linux Docker, GCC 12.2, Mesa 22.3.6 lavapipe (CPU), Xvfb, сеть отключена.
По одному последовательному сеансу: 180 кадров, warmup 30, retained 150.
Профили без screenshot/readback; percentiles независимо пересчитаны из сырых rows.

CPU wall включает ожидание предыдущего submit/present; это не GPU timestamps и не FPS.
Startup шумит и включает открытие графики; число начальных mesh builds меняется.
Размеры выполняют разную работу: один software-GPU прогон не устанавливает
устойчивый коэффициент производительности. Ёмкости исключают allocator/driver/RSS/VRAM,
а байты блока — длина growable массива, без его возможного запаса. Все чанки резидентны.
